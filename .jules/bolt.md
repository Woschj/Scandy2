## 2024-05-15 - Bulk-Fetching with $in to solve N+1 in Loops
**Learning:** Iterating through rows in `ExcelExportService._create_lendings_sheet()` and running `mongodb.find_one()` inside the loop for tools and workers triggered massive N+1 queries. When benchmarking 10,000 lendings, this resulted in 20,000 extra queries, taking 35+ seconds.
**Action:** Always pre-fetch required relations in batch before a loop using the MongoDB `$in` operator. Gather a unique set of identifiers (like `tool_barcodes = list({l.get('tool_barcode') for l in lendings if l.get('tool_barcode')})`), run a single `mongodb.find()`, and construct O(1) lookup dictionaries (like `tools_map = {t['barcode']: t for t in tools_list}`). Ensure you use variable names that won't trip `flake8` E741 (e.g., use `lend` instead of `l` in comprehensions). This reduced DB calls to 3 and time to ~0.9 seconds.
