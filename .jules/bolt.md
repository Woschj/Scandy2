## 2024-05-15 - Optimize N+1 Query in Excel Export Tools Loop
**Learning:** In `app/services/excel_export_service.py`, looping over tools and running `mongodb.find_one` for each tool to find related `lendings` and `workers` creates a severe N+1 bottleneck during data export.
**Action:** Replaced the N+1 loop with single bulk queries (`mongodb.find('lendings', {'returned_at': None})` and `mongodb.find('workers', {'deleted': {'$ne': True}})`). Mapped results to dictionaries by `tool_barcode` and `barcode` respectively for fast O(1) lookups inside the loop, significantly accelerating the export process from O(N) queries to O(1) queries. Leftover benchmark/test scripts (`mock_perf.py`, etc.) should always be cleaned up before committing.
