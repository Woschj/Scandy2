# Plugin Packages

This directory contains standalone ZIP packages for optional Scandy plugins. These can be installed via the Admin Plugin management interface (`/admin/plugins`).

## Available Plugins:

- `jobs.zip`: Job Board (Jobbörse) feature.
- `weekly_reports.zip`: Weekly Reports (Wochenplan) feature.
- `software_management.zip`: Software & User Group management.
- `canteen.zip`: Canteen Plan (Kantinenplan) feature.

## Installation:

1. Log in as an Administrator.
2. Go to **Plugins** in the administration menu.
3. Click on **Plugin hochladen**.
4. Select one of the ZIP files from this directory.
5. After successful upload, restart the application to activate the new plugin.
